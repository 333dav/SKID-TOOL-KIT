# 🛠️ SKID TOOL KIT
---
This is a Python toolkit designed to run directly in your terminal. It includes security, networking, cryptography, and automation modules.

## 📋 Prerequisites

Before you begin, you must have **Python 3** installed on your computer.

## 🚀 How to Install and Run

Choose the instructions based on your operating system:

### 🪟 On Windows (Command Prompt or PowerShell)

1. **Download the project** or clone the repository:
   ```cmd
   git clone https://github.com/333dav/SKID-TOOL-KIT.git
   cd SKID-TOOL-KIT
   ```

2. **Install the required dependencies**:
   ```cmd
   pip install -r requirements.txt
   ```

3. **Start the program**:
   ```cmd
   python main.py
   ```

---

### 🐧 On Linux (Ubuntu/Debian and derivatives)

1. **Open the terminal** and download the project:
   ```bash
   git clone https://github.com/SKID-TOOL-KIT.git
   cd SKID-TOOL-KIT
   ```

2. **Install the dependencies**:
   ```bash
   pip3 install -r requirements.txt
   ```
   *If you get an "ERROR", ask an AI or run these commands to use a virtual environment:*
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip3 install -r requirements.txt
   ```
   
3. **Start the program**:
   ```bash
   python3 main.py
   ```

## 📂 Project Structure

* `main.py`: Main file that launches the terminal menu.
* `modules/`: Folder containing the tools (Bruteforce, Cryptography, Networks, Malware, etc.).
* `utils/`: Helper functions for display and interface rendering.
